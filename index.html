2. Art3m1s/Arya — Cross-Platform Visual Novel Runtime

Proyek fork runtime lintas platform untuk menjalankan gim berbasis Artemis Engine secara langsung tanpa proses porting manual per judul gim.

  • Arsitektur terpisah: Rust (art3m1s-core) untuk eksekusi skrip & rendering 60 FPS via C FFI, serta Flutter untuk manajemen pustaka & UI.
  • Pembacaan arsip .pfs secara in-place dari penyimpanan tanpa menyalin ulang data besar.
  • Dukungan animasi karakter 2D (E-Mote), pemutaran video via FFmpeg, dan patch terjemahan.
